# Fonts

The banner page (`scripts/banner.html`) draws the image shown when ferrocrypt.app is shared
with the desktop app's Inter, as the banners drawn from the same page in the ferrocrypt
repository are. The site's own `public/fonts/Inter-Latin.woff2` draws the image's letters a
little differently.

- `Inter-Regular.woff2`, `Inter-SemiBold.woff2`, `Inter-Bold.woff2`: Inter 4.1, the TTF files
  in ferrocrypt's `ferrocrypt-desktop/fonts/`, compressed to WOFF2 with `woff2_compress` and
  otherwise unchanged. Licensed under the SIL Open Font License 1.1: `OFL.txt`.
